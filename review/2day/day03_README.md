## ① 知识速整清单

### 1. 函数的定义与调用
- `def 函数名(参数): 函数体`，函数体必须缩进
- 先定义再调用
- 函数名命名规则同变量名

### 2. 形参 vs 实参
- 形参：定义函数时的参数（占位）
- 实参：调用函数时传入的实际值
- 值传递 vs 引用传递：Python 是"传对象引用"

### 3. 参数的五种形式
| 形式 | 语法 | 说明 |
|---|---|---|
| 位置参数 | `def f(a, b)` | 按位置传参 |
| 默认参数 | `def f(a, b=10)` | 不传就用默认值 |
| 关键字参数 | `f(a=1, b=2)` | 调用时指定参数名，不怕顺序 |
| 可变位置参数 | `def f(*args)` | 任意个位置参数，打包成元组 |
| 可变关键字参数 | `def f(**kwargs)` | 任意个"名字=值"，打包成字典 |

### 4. 解包传参
- `*list`：把列表解包成位置参数
- `**dict`：把字典解包成关键字参数
- 强制位置/关键字参数：`/`（前面必须位置传）、`*`（后面必须关键字传）

### 5. 返回值
- 无 `return` 返回 `None`
- 多值返回：`return a, b`，本质是元组
- 解包接收：`x, y = f()`

### 6. 变量作用域
- 局部作用域 → 全局作用域 → 内置作用域（LEGB）
- 局部优先
- `global`：修改全局变量
- `nonlocal`：修改外层（非全局）函数的局部变量

### 7. 递归
- 三要素：出口（base case）+ 递推式 + 规模缩小
- 阶乘：`f(n) = n * f(n-1)`，出口 `f(1) = 1`

### 8. 匿名函数 lambda
- 语法：`lambda 参数: 表达式`
- 常用于 `sorted(key=lambda)`、`max(key=lambda)` 等

### 9. 高阶函数
- `map(fn, 序列)`：对每个元素应用函数
- `filter(fn, 序列)`：过滤元素
- `reduce(fn, 序列)`：累积计算

## ② 方法地图

| 想干什么 | 写法 | 易混点 |
|---|---|---|
| 定义函数 | `def add(a, b): return a+b` | 别忘了冒号和缩进 |
| 默认参数 | `def f(a, b=10)` | 默认参数必须放最后 |
| 接收任意个参数 | `def f(*args, **kwargs)` | args 是元组，kwargs 是字典 |
| 解包传参 | `f(*list, **dict)` | 调用时解包 |
| 修改全局变量 | `global x; x = 10` | 别滥用 |
| 排序按某个键 | `sorted(lst, key=lambda x: x[1])` | lambda 返回排序依据 |
| 批量处理 | `list(map(fn, lst))` | map 返回迭代器，要转 list |
| 过滤 | `list(filter(fn, lst))` | fn 返回 True 保留 |
