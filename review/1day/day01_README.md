## ① 知识速整清单

### 1. 变量
- 创建：`变量名 = 变量值`，赋值后变量才被创建
- 多变量赋值：`a, b, c = 1, 2, 3`
- 命名规则：字母/下划线开头，不能数字开头，不与关键字重名
- 命名风格：大驼峰 `NameId`、小驼峰 `lowerCamelCase`、蛇形 `name_id`
- 常量约定：全大写 `PI = 3.14159`

### 2. 数据类型与类型转换
| 类型 | 说明 | 转换函数 |
|---|---|---|
| int | 整数 | `int(x)` |
| float | 浮点数 | `float(x)` |
| bool | 布尔（True/False，0=False，1=True） | `bool(x)` |
| str | 字符串 | `str(x)` |

### 3. 进制
- 二进制 `0b`、八进制 `0o`、十六进制 `0x`
- 转换函数：`bin(x)`、`oct(x)`、`hex(x)`
- 字符与 ASCII：`ord('A')` → 65，`chr(65)` → 'A'

### 4. 输入输出
- `input("提示")`：接收用户输入，返回字符串
- `print()`：输出，支持多参数、格式化

### 5. 运算符
- 算术：`+ - * / // % **`
- 比较：`== != > < >= <=`
- 逻辑：`and or not`
- 赋值：`= += -= *= /= //=`

### 6. 流程控制
- 分支：`if / elif / else`
- 循环：`for ... in ...`、`while ...`
- 循环控制：`break`（跳出）、`continue`（跳过本次）、`pass`（占位）

## ② 方法地图

| 想干什么 | 写法 | 易混点 |
|---|---|---|
| 定义变量 | `x = 10` | Python 是动态类型，不用声明类型 |
| 接收输入 | `name = input("姓名：")` | 返回的是字符串，数字要自己转 |
| 分支判断 | `if x > 0: ... elif x == 0: ... else: ...` | 注意冒号和缩进 |
| for 循环 | `for i in range(5): ...` | range 左闭右开，0~4 |
| while 循环 | `while 条件: ...` | 别忘了改条件，否则死循环 |
| 跳出循环 | `break` | 只跳出最近一层循环 |
| 跳过本次 | `continue` | 直接进入下一次迭代 |
