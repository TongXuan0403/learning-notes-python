## ① 知识速整清单

### 1. 序列共性（list / str / tuple）
- 都是有序序列，支持索引、切片、`len()`、`in`、遍历
- 切片语法：`[start:stop:step]`，左闭右开
- 支持相加（拼接）、相乘（重复）

### 2. 列表 List（可变）
**增**：
- `append(x)`：末尾添加，把整体当一个元素
- `extend(可迭代)`：末尾逐个添加
- `insert(i, x)`：指定位置插入

**删**：
- `pop(i)`：按位置删除，默认删末尾
- `remove(x)`：按值删除第一次出现的
- `del lst[i]`：删除指定位置或切片
- `clear()`：清空

**改**：`lst[i] = x`

**查**：`index(x)`、`count(x)`、`x in lst`

**排序**：`sort()` 原地排序 vs `sorted()` 返回新列表

**其他**：嵌套列表、列表推导式 `[表达式 for x in 序列 if 条件]`、`zip()` 并行遍历

### 3. 字符串 String（不可变）
- `split(x, n)`：按分隔符分割，可指定最大次数
- `x.join(seq)`：用 x 连接序列中的字符串
- `replace(old, new)`：替换
- `strip(x)`：去掉两边空格或指定字符
- `find(x)`：找索引，找不到返回 -1
- `count(x)`：统计出现次数
- `startswith(x)` / `endswith(x)`：判断开头/结尾
- `upper()` / `lower()`：大小写转换
- `isalpha()` / `isdigit()` / `isspace()`：判断字符类型

### 4. 元组 Tuple（不可变）
- 创建：`t = (1, 2, 3)` 或 `t = 1, 2, 3`
- 单元素：`t = (1,)`，必须带逗号
- 不可修改，适合存常量
- 解包：`a, b, c = t`

### 5. 集合 Set（无序、不重复）
- 创建：`s = {1, 2, 3}` 或 `set()`
- 特性：自动去重
- 运算：交集 `&`、并集 `|`、差集 `-`、对称差 `^`

### 6. 字典 Dict（键值对）
- 创建：`d = {"name": "张三", "age": 18}`
- 增删改查：`d[key] = value`、`del d[key]`、`d.get(key, 默认值)`
- 遍历：`keys()`、`values()`、`items()`
- 计数技巧：`d[k] = d.get(k, 0) + 1`

## ② 方法地图

| 想干什么 | 写法 | 易混点 |
|---|---|---|
| 列表末尾加一个 | `lst.append(x)` | 把 x 当整体加进去 |
| 列表末尾加多个 | `lst.extend(可迭代)` | 逐个元素加进去 |
| 列表排序 | `lst.sort()` | 原地改，返回 None |
| 列表排序（新列表） | `sorted(lst)` | 不改原列表 |
| 字符串分割 | `s.split(",")` | 返回列表 |
| 字符串连接 | `",".join(list)` | 参数是字符串列表 |
| 字典取值（安全） | `d.get(key, 默认值)` | 取不到不报错 |
| 字典计数 | `d[k] = d.get(k, 0) + 1` | 统计词频标配 |
| 去重 | `list(set(lst))` | 顺序会乱 |
| 并行遍历 | `for a, b in zip(list1, list2)` | 按短的那个截断 |
