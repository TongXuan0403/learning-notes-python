## ① 知识速整清单

### 1. 类与对象
- 类是模具，对象是用模具压出来的月饼
- 类是宏观的、抽象的；对象是具体的
- `class 类名:` 定义类，`类名()` 创建对象

### 2. __init__ 初始化方法
- 创建对象时自动调用
- `self` 不用手动传，Python 自动传
- 作用：初始化对象的属性

### 3. self
- 调用 `对象.方法()` 时，Python 自动把这个对象传进 `self`
- 相当于 Java 的 `this`
- 在方法内部通过 `self` 访问和修改对象的属性

### 4. 类属性 vs 实例属性（最大的坑！）
| | 类属性 | 实例属性 |
|---|---|---|
| 写在哪 | 类里、方法外 | `__init__` 里 `self.x = ...` |
| 归属 | 所有对象共享一份 | 每个对象各一份 |
| 典型用途 | 计数器、注册表、共享常量 | 对象各自的数据 |

⚠ **坑**：方法里 `self.count += 1` 不会改类属性！它会偷偷新建一个同名**实例属性**。改类属性要用 `类名.count += 1` 或 `type(self).count += 1`。

### 5. 三种方法
| 类型 | 装饰器 | 第一参数 | 能访问什么 | 什么时候用 |
|---|---|---|---|---|
| 实例方法 | 无 | self | 实例属性 + 类属性 | 90% 的普通方法 |
| 类方法 | `@classmethod` | cls | 类属性 | 计数器/注册表/备选构造 |
| 静态方法 | `@staticmethod` | 无 | 都不能直接访问 | 逻辑属于类但不依赖状态 |

### 6. 封装
- **私有属性**：`self.__x`，外部 `obj.__x` 取不到
  - 本质是 Python 自动做了**名称改写（Name Mangling）**：改成 `_类名__x`
  - 君子协定，不是真锁
- **内部约定**：`self._x`，单下划线告诉别人"别从外面碰"
- **@property**：把方法伪装成属性
  - 读：`@property` 修饰方法，访问时 `obj.temperature` 不加括号
  - 写：`@属性名.setter`，赋值时自动执行，可做校验

### 7. 继承
- 单继承：`class 子类(父类):`
- 多继承：`class 子类(父类1, 父类2, ...):`
- 调父类方法：`super().方法名()` 或 `父类名.方法名(self)`
- **方法重写**：子类定义与父类同名的方法，调用时调子类的
- ⚠ **坑**：子类重写 `__init__` 后，不会自动调父类的 `__init__`，必须显式 `super().__init__()`

### 8. 多态与鸭子类型
- 不看对象是什么类型，只看它有没有那个方法
- "走起来像鸭子，叫起来像鸭子，就是鸭子"
- 不同子类都有同名方法，函数里直接调，不写 if 判断类型

### 9. 常用魔术方法（dunder）
| 魔术方法 | 什么时候自动被调用 | 你要做的 |
|---|---|---|
| `__init__` | `类名()` 创建对象时 | 初始化属性，不要 return |
| `__str__` | `print(obj)`、`str(obj)` | **return** 一个给人看的字符串（不是 print！） |
| `__repr__` | 调试、放进容器里显示 | return 给开发者看的字符串 |
| `__len__` | `len(obj)` | return 整数 |
| `__getitem__` | `obj[i]`、切片 | return 对应位置元素 |
| `__call__` | `obj(...)` 把对象当函数调 | 写调用逻辑 |

> 实现了 `__len__ + __getitem__`，你的对象就能像列表一样被 `len()`、下标、切片、遍历 —— 这就是鸭子类型。

## ② 方法地图

| 想干什么 | 写法 | 易混点 |
|---|---|---|
| 定义类 | `class Dog: ...` | 类名大驼峰 |
| 初始化属性 | `def __init__(self, name): self.name = name` | self 自动传，不用手动传 |
| 创建对象 | `d = Dog("旺财")` | 自动调 `__init__` |
| 类属性 | `class Kind: kind = "犬科"` | 共享一份，别用 self 改 |
| 实例属性 | `self.name = name` | 每个对象各一份 |
| 实例方法 | `def bark(self): return f"{self.name}: 汪汪"` | 第一个参数永远是 self |
| 类方法 | `@classmethod def add(cls, name): ...` | 第一个参数是 cls |
| 静态方法 | `@staticmethod def help(): ...` | 没有 self/cls |
| 私有属性 | `self.__api_key = k` | 会被改名成 `_类名__api_key` |
| property 读 | `@property def temperature(self): ...` | 访问时不加括号 |
| property 写 | `@temperature.setter def temperature(self, v): ...` | 赋值时自动执行 |
| 继承 | `class Qwen(BaseModel): ...` | 括号里写父类 |
| 调父类初始化 | `super().__init__(name)` | 子类写了 `__init__` 必须显式调 |
| 打印对象 | `def __str__(self): return "..."` | **return**，不是 print！ |
| 判断类型 | `isinstance(obj, 类)` | 子类实例对父类也返回 True |
